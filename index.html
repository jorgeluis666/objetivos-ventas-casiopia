Configurar sincronización

Para disparar la sincronización desde el dashboard, pegá un Personal Access Token de GitHub del repo objetivos-ventas-casiopia con permisos Actions: read and write y Contents: read (o un token clásico con scope workflow). El token se guarda solo en tu navegador (localStorage).

Sin token, los datos igual se actualizan solos: Gasto publicitario todos los días a las 07:00 (Lima) vía el cron del workflow.
